Dart Tournament – Kurzanleitung
================================

Voraussetzung
-------------
- Node.js 18 oder neuer (LTS) von https://nodejs.org
- Laptop und Handys im GLEICHEN WLAN (kein Gast-WLAN)

Starten
-------
Windows:      "Start-Windows.bat" doppelklicken
macOS:        "Start-Mac-Linux.command" doppelklicken
              (beim ersten Mal: Rechtsklick -> Öffnen)
Linux:        ./Start-Mac-Linux.command

Ein Fenster mit den Adressen erscheint – NICHT schliessen!
Der Browser öffnet sich automatisch auf http://localhost:3000

Spielen
-------
1. Am Laptop Turnier erstellen, Spieler eintragen, Turnier starten.
2. Handys scannen den QR-Code auf dem Turnier-Bildschirm.
3. Am Handy das Spiel wählen, PIN vom Laptop eingeben, Würfe eintragen.

Probleme?
---------
- Fenster schliesst sofort / "Node.js ist nicht installiert":
  Node.js installieren, danach erneut starten.
- Handys verbinden sich nicht:
  * Gleiches WLAN? Gast-WLANs blockieren Geräte untereinander.
  * Windows-Firewall: Zugriff für Node.js in "Privaten Netzwerken" erlauben.
  * Falsche Adresse im QR-Code (z.B. VPN aktiv)? VPN trennen oder
    die richtige IP erzwingen: set HOST_IP=192.168.1.5 (vor dem Start).
- "Port 3000 wird bereits verwendet": Der Server läuft schon in einem
  anderen Fenster.
- Der Turnierstand wird automatisch gespeichert. Nach einem Absturz
  einfach neu starten – das Turnier geht weiter.
