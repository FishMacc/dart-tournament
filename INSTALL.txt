DartVault Dart Tournament - Quick Guide
=======================================

Requirements
------------
- Node.js 18 or newer (LTS) from https://nodejs.org
- Laptop and phones on the SAME Wi-Fi (not a guest network)

Start
-----
Windows:      double-click "Start-Windows.bat"
macOS:        double-click "Start-Mac-Linux.command"
              (first time: right-click -> Open)
Linux:        ./Start-Mac-Linux.command

A window with the addresses appears - do NOT close it!
The browser opens http://localhost:3000 automatically.

Play
----
1. On the laptop: create a tournament, add players, start it.
2. Phones scan the QR code on the tournament screen.
3. On the phone: pick the match, enter the PIN from the laptop, enter darts.

Language: the EN/DE button at the top right switches between English
and German.

Problems?
---------
- The window closes right away / "Node.js is not installed":
  Install Node.js, then start again.
- Phones can't connect:
  * Same Wi-Fi? Guest networks block devices from each other.
  * Windows Firewall: allow Node.js on "Private networks".
  * Wrong address in the QR code (e.g. VPN active)? Disconnect the VPN or
    force the right IP: set HOST_IP=192.168.1.5 (before starting).
- "Port 3000 is already in use": the server is already running in
  another window.
- The tournament is saved automatically. After a crash just start
  again - the tournament continues.
